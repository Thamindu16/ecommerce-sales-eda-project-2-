# Exploratory Data Analysis on E-Commerce Sales Dataset

----- Project Overview -----

This project was completed as part of my Data Analytics Internship at DecodeLabs. The main objective of this project was to perform Exploratory Data Analysis (EDA) on an E-Commerce sales dataset using Python and Pandas in Google Colab.

The analysis was carried out to better understand customer purchasing behavior, sales performance, payment methods, order status, and product trends. Different data analysis and visualization techniques were used to identify useful patterns and insights from the dataset.

During the project, data cleaning steps were also performed by handling missing values and checking duplicate records before starting the analysis process.

----- Technologies Used -----

      * Python
      * Pandas
      * Matplotlib
      * Seaborn
      * Google Colab
      * Microsoft Excel

----- Analysis Performed -----

      * Dataset inspection and understanding
      * Missing value handling
      * Duplicate record checking
      * Product analysis
      * Payment method analysis
      * Order status analysis
      * Monthly sales trend analysis
      * Correlation analysis
      * Outlier detection
      * Data visualization using charts and graphs

----- How to Run the Project -----

     * Open the notebook in Google Colab
     * Upload or connect the dataset
     * Run all notebook cells step by step
     * Execute the analysis and visualization sections
     * Review the generated charts and outputs

----- Key Insights -----

     * Some products showed significantly higher sales compared to others
     * Payment methods varied across customer transactions
     * Monthly sales trends helped identify business performance patterns
     * Correlation analysis showed relationships between numerical variables

This project helped me improve my practical knowledge in:

     * Exploratory Data Analysis (EDA)

     * Data preprocessing and cleaning
     * Understanding sales data patterns using Python
